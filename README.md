# Aventura da Letra V (HTML, CSS e JavaScript)

Este projeto não usa Vite, React, npm ou etapa de compilação.

## Arquivos
- `index.html`
- `style.css`
- `script.js`

## Testar
Abra o arquivo `index.html` no navegador.

## Publicar no Vercel
1. Envie os três arquivos para a raiz de um repositório no GitHub.
2. Importe o repositório no Vercel.
3. Em Framework Preset, selecione **Other**.
4. Deixe Build Command e Output Directory vazios.
5. Clique em Deploy.

O Vercel vai servir diretamente o `index.html`.
